# taylor

Taylor Ranch Log Book Collection was originally a small CONTENTdm only collection created in 2011.

CDIL fellow Ricky Lee Baldridge created summaries and highlights for the logbooks in 2019.
It was an early CB-SA project, https://github.com/uidaholib/taylor_source

It was migrated 2026.

It has a custom logbook display_template. 
The items are described in "taylor.csv".
Highlights are described in "taylor_ranch_feature_pages.csv"
